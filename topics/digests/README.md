# Digests

One file per week, named `YYYY-MM-DD.md` (the Monday it was generated),
written by the scheduled forecasting-news crawl. Expected shape:

```markdown
# Forecasting digest — YYYY-MM-DD

## What's new
- [Title](link) — one or two sentences on what it is and why it showed up.
- ...

## Candidate topics this week
- **Topic idea** — source: [link]. Why: one line. (Also appended to
  ../backlog.md if not already there.)
```

These are a research log, not blog drafts — terse and link-forward. See
[../README.md](../README.md) for how a digest turns into a post.
